# 首都高ドライブ

ブラウザで遊べる首都高ドライブゲーム（three.js）。C1 都心環状線（内回り）と B 湾岸線（湾岸市川 ⇄ 空港中央）を走れます。

## 遊び方

- 横向きで遊びます（縦向きだと案内が出ます）
- 左下 ◀ ▶ でハンドル、右下でアクセル／ブレーキ
- PC：矢印キー or WASD、N で昼夜切替、C で視点切替
- 右上 ☰：昼夜、雨、視点、画質、音、タイトルへ
- スマホのホーム画面に追加すると全画面アプリとして起動できます

## 機能

- 首都高・関東の高速道路をつなげて自由に走行（コース選択なし）
  - OpenStreetMap（Overpass API）から、走っている場所の周りの高速道路データを順に読み込み
  - ジャンクションでは、左右どちらの車線にいるかで進む道を選択（画面上の緑の案内に表示）
  - 高架・地上・トンネルは地図の bridge / layer / tunnel 情報から推定
  - 一度読み込んだデータはブラウザに保存され、次回から速く起動
  - 地図データを取得できないときは簡易版の都心環状線で走行
- 沿線の実在の建物（形・高さ）を表示、その外側は自動生成の街
- 高精細な車モデル（glTF）、昼・夕方・夜、雨（濡れた路面の反射）
- 光のにじみ（ブルーム）、色調補正、影、空の映り込み

## GitHub Pages で公開する手順

1. このフォルダのファイル（`index.html`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `README.md`）をリポジトリに置く
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます
